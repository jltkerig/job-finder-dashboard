Résumé Rules

Your standing instructions for every résumé. Claude Desktop reads them before writing, and they win over its built-in rules. To change one for a single job, say so when you ask. Kept only on this computer.

How to write them: put each rule on its own line, starting with a dash (-). A line without a dash is a heading that groups the rules under it. Leave a blank line between groups. Write them the way you would tell a person; no special symbols are needed.

Cover Letter Rules

Your standing instructions for every cover letter, including how to explain an employment gap. Claude Desktop reads them before writing. Kept only on this computer.

How to write them: put each rule on its own line, starting with a dash (-). A line without a dash is a heading that groups the rules under it. Leave a blank line between groups. Write them the way you would tell a person; no special symbols are needed.
